## ◈ THE IDEA

Your conversations belong to you.

**ERROR MESSENGER** is a privacy-focused desktop messaging application designed around one fundamental principle: communication should remain personal.

No unnecessary complexity. No compromise on the importance of privacy. Just a modern messaging experience with a strong focus on secure, direct communication.

## ◈ BUILT AROUND PRIVACY

| PRINCIPLE | DESCRIPTION |
|:--|:--|
| **Privacy First** | Designed to minimize unnecessary exposure of personal conversations. |
| **Secure Communication** | Focused on protecting messages while they are transmitted. |
| **Peer-to-Peer** | Supports direct communication between connected users. |
| **User Control** | Communication designed around the people using it. |
| **Minimal Experience** | A clean, modern interface without unnecessary distractions. |

## ◈ SECURITY BY DESIGN

Privacy is not an extra feature. It is a design priority.

ERROR MESSENGER uses peer-to-peer communication technology to establish direct connections between users. Its architecture is designed to keep message content out of the signaling service.

Communication security remains an ongoing development priority. The project does not claim absolute security or independently audited end-to-end encryption.

## ◈ TECHNOLOGY

Built with modern technologies to deliver a responsive and reliable desktop experience.

- **Frontend:** React, Vite, TypeScript
- **Desktop:** Electron
- **Backend:** Python, FastAPI
- **Communication:** WebRTC DataChannel
- **Database:** SQLite

## ◈ PLATFORM

**Windows Desktop**

A standalone desktop experience, designed to make private communication accessible and straightforward.

## ◈ DEVELOPMENT

ERROR MESSENGER is actively evolving.

The project is continuously being improved, with a focus on privacy, reliability, usability, and a better communication experience.
